# AI Complaint Categorization Tool

This project is an AI-powered complaint classification system that automatically categorizes customer complaints using Natural Language Processing (NLP) and Machine Learning techniques.

## Features
- Automatic complaint categorization
- NLP text preprocessing
- TF-IDF vectorization
- Logistic Regression ML model
- Flask backend API
- Responsive frontend UI
- Real-time prediction system
